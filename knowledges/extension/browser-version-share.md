# ブラウザのバージョン別シェア

- 確認日: 2026-11-17
- 方法: Web 検索で公開資料を読んだ。この拡張の利用者の内訳ではない
- 注意: シェアは集計元によって大きく違う。小さい値ほど誤差が大きい

## Firefox

StatCounter の 2026 年 10 月のデータです（[Wikipedia の Firefox version history](https://en.wikipedia.org/wiki/Firefox_version_history) に載っている表による）。

| バージョン | Firefox の中での割合 | 全ブラウザの中での割合 |
|---|---|---|
| 115 / 115 ESR | 4.69% | 0.12% |
| 120 | 2.73% | 0.07% |
| 121 | 5.47% | 0.14% |
| 123 | 1.17% | 0.03% |
| 124 | 1.95% | 0.05% |
| 125 | 0.78% | 0.02% |
| 128〜139 | 1.17% | 0.03% |
| 140〜152 | 7.42% | 0.19% |
| 153 / 153 ESR | 1.56% | 0.04% |
| 154〜156 | 6.25% | 0.16% |
| 157 | 27.73% | 0.71% |
| 158 | 27.34% | 0.70% |
| 159 | 4.69% | 0.12% |
| 合計 | 100% | 2.56% |

- 128 未満（115〜125）の合計は約 16.8%（全ブラウザの中では約 0.43%）です。
- 120・121 の割合が高い理由はわかりません。

### ESR 115 はまだ更新されている

- ESR 115 は、Windows 7〜8.1 と macOS 10.12〜10.14 向けに更新が続いています。それ以外の OS の利用者には ESR 140 への移行が案内されています（[Firefox ESR 115.41.0 のリリースノート](https://www.firefox.com/en-US/firefox/115.41.0/releasenotes/)）。
- Wikipedia では、2026-11-10 に 115.45.0esr が出たとされています（[Firefox](https://en.wikipedia.org/wiki/Firefox)）。
- 今の ESR は 153 です（同上）。

## Chrome

- 2026-11-11 時点のデスクトップの最新は 157 です（[Google Chrome](https://en.wikipedia.org/wiki/Google_Chrome)）。
- StatCounter の 2026 年 10 月のデスクトップの表では、上位は 155（16.75%）、154（15.4%）、156（5.89%）でした（[StatCounter](https://gs.statcounter.com/browser-version-market-share/desktop/worldwide/)）。
- 100 番台前半の版ごとのシェアは見つかりませんでした。
- Windows 7 / 8.1 で使える Chrome は 109 が最後です（一般に知られている事実。今回の資料では確かめていません）。
- Windows 7 は Windows 全体の 0.43% です（StatCounter、2026 年 10 月）。ただし StatCounter は、2025 年に Windows 7 の数字を誤って集計し、あとで直したと報じられています（[Windows Latest](https://www.windowslatest.com/2025/10/02/no-windows-7-isnt-gaining-market-share-in-2025/)）。
