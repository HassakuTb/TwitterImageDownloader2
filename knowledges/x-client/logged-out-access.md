# ログアウト状態で見られるページ

- 確認日: 2026-11-17
- 方法: Chrome の User-Agent を付けて curl で取得（`-L` でリダイレクトを追跡）

## 結果

| ページ | ログアウト時 | 配信クライアント | 取れたもの |
|---|---|---|---|
| ツイート詳細 `/<user>/status/<id>` | 見られる | x-web | `article` 6 件、`/photo/N` リンク 9 件 |
| プロフィール `/<user>` | 見られる | x-web | `article` 6 件、`/photo/N` リンク 6 件 |
| メディアタブ `/<user>/media` | ログイン画面（`/i/jf/onboarding/web?...`）に飛ばされる | — | なし |
| ホーム `/home` | トップページ（ランディング）に飛ばされる | — | なし |

ツイート詳細とプロフィールでは、ログインを促す表示が出ますが、ツイート本体はその後ろに描画されています。

## わかること

- 新クライアントの DOM は、ツイート詳細とプロフィールでなら調べられます。
- メディアタブとホームの新クライアント版は確認できません。ログインしないと見られず、ログイン時はまだ旧クライアントが配信されるためです。
- 新クライアントのライトボックスは JavaScript で描画されるので、SSR からは確認できません。

## ログアウト状態を作る方法

ログイン済みの Chrome で Claude in Chrome を使うと、ログイン状態（旧クライアント）になります。ログアウト状態を調べる方法は 2 つあります。

- **curl で SSR の HTML を取得する**: 手軽です。ただし JavaScript が動いた後の DOM とは違う可能性があります。
- **X にログインしていない別の Chrome プロファイルを使う**: そのプロファイルにも Claude in Chrome が必要です。実際の DOM を確認できます。
